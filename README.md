# Sales-Performance-Analysis-Excel
Excel-based sales data analysis project focusing on profitability, customer segments, regional performance, and interactive dashboards
## 📌 Project Overview
This project focuses on analysing 1,000 sales records using Microsoft Excel to evaluate business performance, sales trends, and profitability. It transforms raw sales data into meaningful business insights through data analysis, Pivot Tables, and visualisation.

The project explores customer purchasing patterns, product category performance, regional sales distribution, discount impact, and shipment methods to support data-driven business decisions.

## 🎯 Project Objectives
- Analyse overall sales and profit performance.
- Identify top-performing product categories and subcategories.
- Evaluate sales across different customer segments.
- Compare regional sales performance.
- Understand the impact of discounts on profitability.
- Analyse sales trends over time.
- Examine different shipment modes.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Data Analysis
- Interactive Dashboard

## 📂 Project Structure
- Aditya Excel project.xlsx – Main Excel workbook containing:
  - *Data:* Raw sales dataset.
  - *PivotTable:* Summarised sales and profitability analysis.
  - *Dashboard:* Dashboard worksheet.

This analysis helps identify profitable business areas, understand customer behaviour, evaluate regional performance, and provide insights that can support better business planning and strategic decision-making.
